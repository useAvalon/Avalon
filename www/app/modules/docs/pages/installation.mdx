## Requirements

- [Bun](https://bun.sh) 1.0 or later
- Node.js 18+ (if not using Bun)

<DocsSteps>

## Create a new project

The fastest way to get started is with the `create avalon` scaffolder:

```bash
bun create avalon my-app
```

This creates a new directory `my-app/` with a minimal project structure.

## Project setup

```bash
cd my-app
bun install
bun run dev
```

Your site is now running at `http://localhost:3000`.

</DocsSteps>

## Project structure

Scaffolded apps use **modules** (URL prefixes) under `app/`, not a top-level `src/` folder.

<div class="docs-block">

```
my-app/
├── app/
│   ├── modules/
│   │   ├── main/               # Site root (/)
│   │   │   ├── pages/          # File-system routes for this module
│   │   │   ├── components/     # UI, including islands
│   │   │   └── layouts/        # Module layout wrappers
│   │   └── about/              # /about — module name = URL prefix
│   └── shared/
│       ├── layouts/            # Root HTML shell
│       ├── components/
│       └── styles/             # Global CSS (via nitro globalCSS)
├── middleware/                 # Server middleware
├── routes/
│   └── api/                    # API routes (Nitro)
├── server/                     # SSR renderer entry
├── public/                     # Static assets
├── vite.config.ts              # Avalon + Nitro config
├── build.mjs                   # Production build entry
└── package.json
```

</div>

## Manual installation

If you prefer to set up manually:

<DocsSteps>

### Install the core package

```bash
bun add @useavalon/avalon
bun add -d vite nitro
```

### Create a Vite config

```ts
import { defineConfig } from 'vite';
import { avalon } from '@useavalon/avalon';

export default defineConfig(async () => {
  const plugins = await avalon({
    core: 'preact',
    modules: 'app/modules',
    layoutsDir: 'app/shared/layouts',
    integrations: ['preact'],
    nitro: {
      preset: 'node_server',
      streaming: true,
      clientEntry: 'app/entry-client',
      globalCSS: ['app/shared/styles/main.css'],
    },
  });
  return { plugins };
});
```

</DocsSteps>
