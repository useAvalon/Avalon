## Requirements

- [Bun](https://bun.sh) 1.0 or later (recommended)
- Node.js 18+ (npm, pnpm, or yarn)

<DocsSteps>

## Create a new project

The fastest way to get started is with the `create avalon` scaffolder:

<PackageManagerTabs island={{ condition: 'on:client' }} preset="scaffold-and-dev" />

This creates a new directory `my-app/` with a minimal project structure and starts the dev server at `http://localhost:3000`.

</DocsSteps>

## Project structure

Scaffolded apps use **modules** (URL prefixes) under `app/`.

<div class="docs-block">

```
my-app/
├── app/
│   ├── modules/
│   │   ├── main/               # Site root (/)
│   │   │   ├── pages/          # File-system routes for this module
│   │   │   ├── components/     # UI, including islands
│   │   │   └── layouts/        # Module layout wrappers
│   │   └── about/              # /about — module name = URL prefix
│   └── shared/
│       ├── layouts/            # Root HTML shell
│       ├── components/
│       └── styles/             # Global CSS (via nitro globalCSS)
├── middleware/                 # Server middleware
├── routes/
│   └── api/                    # API routes (Nitro)
├── server/                     # SSR renderer entry
├── public/                     # Static assets
├── vite.config.ts              # Avalon + Nitro config
├── build.mjs                   # Production build entry
└── package.json
```

</div>

## Manual installation

If you prefer to set up manually:

<DocsSteps>

### Install the core package

<PackageManagerTabs island={{ condition: 'on:client' }} preset="add-avalon-core" />

### Create a Vite config

```ts
import { defineConfig } from 'vite';
import { avalon } from '@useavalon/avalon';

export default defineConfig(async () => {
  const plugins = await avalon({
    core: 'preact',
    modules: 'app/modules',
    layoutsDir: 'app/shared/layouts',
    integrations: ['preact'],
    nitro: {
      preset: 'node_server',
      streaming: true,
      clientEntry: 'app/entry-client',
      globalCSS: ['app/shared/styles/main.css'],
    },
  });
  return { plugins };
});
```

</DocsSteps>
