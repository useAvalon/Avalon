# Avalon Framework Documentation

Welcome to the comprehensive documentation for the Avalon framework - a modern full-stack framework that combines islands architecture with multi-framework support, file-system routing, and powerful SSR/SSG capabilities.

## Documentation Structure

This documentation is organized into six main sections:

- **[Getting Started](./01-getting-started/)** - Quick onboarding and your first Avalon application
- **[Core Concepts](./02-core-concepts/)** - Understanding Avalon's architecture and philosophy
- **[Features](./03-features/)** - Detailed guides for implementing specific functionality
- **[API Reference](./04-api-reference/)** - Complete technical reference for all APIs
- **[Guides](./05-guides/)** - Best practices, patterns, and advanced implementation guidance
- **[Migration](./06-migration/)** - Framework comparisons and migration guides
