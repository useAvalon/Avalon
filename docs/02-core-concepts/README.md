## Key Principles

- **Static by Default**: Components are static unless explicitly made interactive
- **Progressive Enhancement**: Start with HTML and enhance with JavaScript
- **Framework Agnostic**: Use the best tool for each component
- **Performance First**: Minimal JavaScript by default, load only what's needed
- **Developer Experience**: Simple conventions with powerful capabilities
