# Avalon

Multi-framework islands architecture for the modern web. Ship interactive components with React, Preact, Vue, Svelte, Solid, Lit, or Qwik — all in the same project. Zero JavaScript by default.

## Get started

```bash
npm create avalon@latest
# or
bun create avalon
```

Or read the [documentation](https://useavalon.dev/docs/introduction).
